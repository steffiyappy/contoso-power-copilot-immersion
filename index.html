M365 COPILOT · IMMERSION EXPERIENCE

Contoso Power · M365 Copilot Immersion

A practical, role-based immersion for Contoso Power leaders across HR, PMO, Corporate Secretary, Procurement, Operations, Finance, Strategy, Legal, Business Development, and Corporate Communications. Each exercise is tagged by persona so you focus on what is relevant to your function.

Sessions 20 May · 10 June Duration 1.5 hours each Format Demo + Guided hands-on Licensing Microsoft 365 Copilot

About this workshop

Two short, focused immersions. Same platform, two different audiences and depths.

What you will leave with

  • Hands-on experience with Copilot Chat, Researcher, Excel, Word, PowerPoint, and Cowork
  • One persona-specific artefact you built yourself — minutes, board paper, dashboard, or microsite
  • A clear mental model of where Copilot adds value across your function, and where it does not

What this workshop is not

  • It is not a feature walkthrough — every tool is demonstrated in a Contoso Power context
  • It is not connected to live Contoso Power systems — all data is sample / anonymised
  • It is not about replacing judgment — Copilot drafts, you decide

Agents tab (inside Microsoft 365 Copilot Chat)

🔍
Researcher

Deep multi-step web + work research. "Critique" mode auto-reviews sources for reliability before producing the final report.

📈
Analyst

Drop in a dataset; ask complex questions — peer benchmarks, valuation, variance analysis. Writes and runs Python in a secure sandbox.

📄
Word agent

The standalone Word agent in the Agents tab. Generate full Word documents — board papers, policies, briefings — from a prompt + uploaded files, without opening Word.

🖼
PowerPoint agent

The standalone PowerPoint agent in the Agents tab. Turn a memo, Word doc, or prompt into a finished deck with images, layouts, and speaker notes.

📑
Excel agent

The standalone Excel agent in the Agents tab. Build workbooks, models, and dashboards from a prompt or uploaded data — returns a ready-to-use .xlsx.

📋
Planner agent

The Microsoft 365 Copilot agent for Microsoft Planner. Create plans and tasks from natural language, surface at-risk work, generate weekly status updates — grounded in your actual Planner data.

👥
Cowork

Delegate multi-step tasks: "analyse the data, draft a one-pager, build an HTML status page". Cowork plans, checks in, then executes.

How to find the agents: In Microsoft 365 Copilot Chat, click the Agents tab in the left rail (or the agents icon at the top). Researcher, Analyst, Word agent, PowerPoint agent, Excel agent, Planner agent and Cowork all live there as separate agents — pick one per thread.
Data privacy reminder: Do not paste real plant operational data, employee identifiable information, or commercially sensitive Contoso Power data during this session. Use the sample files provided. Microsoft 365 Copilot keeps prompts and data within your tenant boundary and is not used to train foundation models.

Exercise 1 · Daily Ops Performance — Power BI-ready summaryPersona: Operations (Thermal) · PMO

Ops-Thermal PMO ⏱ 25 minutes · 4 core + 3 stretch steps 📎 01 ContosoPower_Thermal_Plant_Performance.xlsx

Turn raw plant performance data into a board-quality KPI summary in 5 minutes

You receive the daily plant performance dump every morning — 6 plants, 30 days, 13 columns. Today, Copilot does the analysis and produces a one-page Pro dashboard summary ready to drop into Power BI.

🎯 CORE · Step 1 · Open Excel and load the file Excel Copilot
Download 01 ContosoPower_Thermal_Plant_Performance.xlsx, open in Excel desktop, open Copilot pane.
🎯 CORE · Step 2 · Ask Copilot to summarise Excel Copilot
Summarise the Daily Performance sheet by plant. For each plant give: average availability %, average heat rate, total forced outage hours, average SLA compliance, and a RAG status against the Targets sheet. Flag any plant that breached the red threshold on any KPI. Format as a clean table I can paste into Power BI.
🎯 CORE · Step 3 · Build the trend chart Excel Copilot
Create a chart showing daily availability % across all 6 plants for the 30-day window. Highlight any day where any plant dropped below 90%. Add a target line at 95%.
🎯 CORE · Step 4 · Generate the management commentary Excel Copilot
Write a 5-bullet management commentary on the month's performance. Quantify everything. Lead with the biggest risk. End with one recommendation.
✨ STRETCH · Step 5 · Same data, deeper questions Analyst
Open Microsoft 365 Copilot Chat → Agents tab → Analyst. Upload the same xlsx.
Compare the 6 thermal plants head-to-head: which plant gives the best availability-to-heat-rate trade-off? Which plant has the most variable performance day-to-day (use coefficient of variation)? Run a quick correlation between forced outage hours and SLA compliance. Output a ranking table plus a 3-bullet investment-prioritisation view.
✨ STRETCH · Step 6 · Build a fleet rollup workbook from a prompt Excel agent
In Copilot Chat → Agents tab → Excel agent (standalone — generates a new .xlsx, no Excel open).
Generate a single-sheet Fleet Operations Rollup workbook for Contoso Power's 6 thermal plants. Columns: Plant ID, Capacity (MW), MTD Availability %, MTD Heat Rate (kJ/kWh), Forced Outage Hours, SLA Compliance %, RAG. Add a totals/weighted-average row. Include conditional formatting (Green ≥95%, Amber 90–94%, Red <90% on Availability). Add a 2nd hidden sheet with assumptions. Make it ready to share to the COO. Output the .xlsx.
✨ STRETCH · Step 7 · Turn the summary into an Ops Review deck PowerPoint Copilot
Save the workbook from Steps 2–4 first. Open a blank PowerPoint, open the in-app Copilot pane.
Create a 5-slide Operations Review deck from my Excel summary: 1) Title — "Thermal Fleet Operations Review · 30-day", 2) Fleet KPI snapshot, 3) Best vs worst performer, 4) Top 3 risks & mitigations, 5) Decisions sought from COO. Clean corporate look, navy accents. Add speaker notes.
What you take away: a Power BI-ready summary, a trend chart, a written commentary, an Analyst deep-dive, a fleet rollup workbook and a 5-slide Ops Review deck — all from the same starting file.

Exercise 2 · Procurement vendor evaluation → Formal minutesPersona: Procurement · Corporate Secretary

Procurement CoSec ⏱ 22 minutes · 4 core + 2 stretch steps 📎 02 ContosoPower_Procurement_Meeting_Transcript.docx

Teams Recap → Word: turn a vendor evaluation meeting into board-quality minutes

Always include this workflow: Teams Recap auto-transcribes the meeting, then Word transforms the transcript into a professional meeting-minutes template — with decisions, rationale, and action items.

🎯 CORE · Step 1 · Open the transcript in Word Word Copilot
Download and open 02 ContosoPower_Procurement_Meeting_Transcript.docx. This simulates the Teams Recap output you would get from a real recorded meeting.
🎯 CORE · Step 2 · Draft formal minutes Word Copilot
Convert this transcript into formal Procurement Committee minutes. Use this structure: 1) Meeting details, 2) Attendees, 3) Subject, 4) Discussion summary (one paragraph per agenda item), 5) Decision, 6) Rationale (three bullets), 7) Action items table with owner and due date. Use neutral, third-person language. No quoted speech.
🎯 CORE · Step 3 · Add a risk & compliance annex Word Copilot
Add an annex at the end titled "Risk & Compliance Notes". Pull every legal, financial and delivery risk mentioned in the transcript. For each: risk, mitigation as discussed, residual concern.
🎯 CORE · Step 4 · Generate the cover email Copilot Chat
Draft a short, professional email from me (Aishah Rahman, Procurement Lead) to the Tender Committee Secretary, attaching these minutes, requesting tabling at the next Tender Committee meeting. Mention the RM 19.8M Sumitec recommendation and the two legal conditions.
✨ STRETCH · Step 5 · Same minutes, standalone agent Word agent
Copilot Chat → Agents tab → Word agent. Attach 02 ContosoPower_Procurement_Meeting_Transcript.docx.
Generate formal Procurement Committee minutes as a Word document from the attached transcript. Structure: meeting details, attendees, subject, discussion summary (one paragraph per agenda item), decision, rationale (3 bullets), action items table. Neutral third-person language. Output the .docx.
Compare the Word Copilot (Step 2, in-app edit mode) vs Word agent (this step, standalone) output.
✨ STRETCH · Step 6 · Pre-award vendor reputation check Researcher
Copilot Chat → Agents tab → Researcher.
Research the three shortlisted vendors — Sumitec Energy, TKM Power Services, and Indkom Industries — for a Malaysian IPP boiler tube replacement contract. For each: ownership, recent contracts in ASEAN power, financial signals from public filings, any litigation, ESG/safety incidents. Use Critique mode to flag any unverified claim. Output a 1-page comparison.
What you take away: publishable minutes (two ways) + risk annex + cover email + a sourced vendor due-diligence brief.

Exercise 3 · PMO portfolio — Planner agentPersona: PMO · Planner agent

PMO Planner agent ⏱ 20 minutes · 3 core + 1 stretch step 📎 03 ContosoPower_PMO_Project_Portfolio.xlsx

From a portfolio spreadsheet to a live Planner plan, at-risk view, and weekly status

The Planner agent in M365 Copilot connects directly to Microsoft Planner. You ask it to bootstrap a plan from your portfolio data, surface at-risk work, and generate the weekly status — grounded in real Planner tasks, not a static export.

Setup note for the facilitator: participants should have access to a Planner plan (Microsoft Planner / Tasks in Teams). For the immersion we use a pre-seeded sample plan called "Contoso Power — Capital Projects" populated from the sample Excel. If not pre-seeded, Step 1 below creates it.
🎯 CORE · Step 1 · Bootstrap a Planner plan from the portfolio Planner agent
Open Microsoft 365 Copilot Chat, mention @Planner, and upload 03 ContosoPower_PMO_Project_Portfolio.xlsx.
@Planner — Create a new plan called "Contoso Power — Capital Projects". For each row in the Capital Projects sheet, create a task with the Project ID and Project Name as the task title, the Project Name as the description, the Target Completion as the due date, and a label for the RAG status (Green/Amber/Red). Group tasks into buckets by Sponsor BU. Confirm the plan before creating.
🎯 CORE · Step 2 · Surface what needs attention Planner agent
@Planner — In the "Contoso Power — Capital Projects" plan, show me every task labelled Red or Amber. For each, give me the bucket, the due date, and how many days until due. Highlight any task already past its due date. Suggest which three need executive attention this week and why.
🎯 CORE · Step 3 · Draft the weekly PMO status update Planner agent
@Planner — Draft this week's PMO status update from the plan, addressed to the Project Steering Committee. Structure: headline (one sentence), RAG summary (counts), top 3 risks with mitigation owner, accomplishments this week, decisions needed next week. Tone: factual, board-grade.
✨ STRETCH · Step 4 · Turn the status into a PMO Review deck PowerPoint agent
In a new Copilot Chat thread → Agents tab → PowerPoint agent. Paste the weekly status from Step 3.
Build a 6-slide PMO Weekly Review deck from the pasted status: 1) Title, 2) Portfolio RAG snapshot, 3) Top 3 at-risk projects with mitigation owners, 4) Accomplishments this week, 5) Decisions needed next week, 6) Forward calendar (next 4 weeks). Corporate look, navy/teal accents. Add speaker notes.
Note: The Planner agent and Cowork are separate Microsoft 365 Copilot agents. You can't chain a Cowork step inside a Planner agent thread — switch agents if you want to do something else (e.g. produce a brand-styled HTML one-pager from the Planner output).
What you take away: a real Planner plan, an at-risk task view, a board-grade weekly status and a 6-slide PMO Review deck — reproducible every Friday with three prompts.

From blank page to first-draft policy and board resolution

HR and Corporate Secretary spend disproportionate time getting to draft one. Copilot gets you to draft three in the time it took to write draft one.

🎯 CORE · HR Path — Hybrid working policy Word Copilot
Draft a Hybrid Working Policy for Contoso Power (Malaysian IPP, ~2,000 employees). Cover: eligibility (note that plant operations roles are not eligible — explain why with operational safety language), default 3 days office / 2 days home for HQ roles, core hours 10am-4pm Malaysia time, equipment and ergonomics, manager approval flow, performance management equivalence, and a 6-month review clause. Tone: professional, clear, Malaysian English. About 600 words.
🎯 CORE · CoSec Path — Board resolution Word Copilot
Draft a Directors' Circular Resolution for Contoso Power Berhad approving the award of the TBE-1 Boiler Tube Replacement contract to Sumitec Energy Sdn Bhd at RM 19.8 million, subject to (a) indemnity cap revision to 100% of contract value and (b) confirmation of parent guarantee structure. Use standard Malaysian listed-company resolution format. Include preamble, the resolution itself, signing blocks for all directors, and a date line. Make it suitable for circulation by the Corporate Secretary.
✨ STRETCH · Step 3 · Build an HR self-service portal (HTML) Cowork
Copilot Chat → Agents tab → Cowork. Attach the policy from the HR Path above.
Build a single self-contained .html HR self-service portal for Contoso Power employees. Include: (a) hero with a friendly welcome and search box (non-functional placeholder is fine); (b) policy cards grid — Hybrid Working, Leave, Claims, Code of Conduct, Whistleblowing, Performance Review (each card shows title, 1-line description, "Read more" button); (c) "My quick links" panel — payslip, leave balance, claim a new expense, raise a ticket; (d) "FAQ" accordion with 6 common HR questions answered using my attached policy as the source; (e) contact HR block with phone, email, HQ address. Inline CSS, responsive at mobile + desktop, navy (#1E3A5F) and teal (#0E7490) accents. Must open in a browser by double-clicking.
What you take away: hybrid working policy, board resolution and a working HR self-service portal — all from a few prompts.
